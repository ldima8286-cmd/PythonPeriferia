# Periferia

[English](README.md) · **Русский** · [Инструкция для чайников](docs/getting-started.ru.md)

**Версия 1.0 — готово.** Глобальный push-to-talk на любую клавишу, виртуальный
микрофон и обработка микрофона для Linux. Python, PipeWire, evdev. Работает на
Wayland.

Микрофон закрыт, пока ты держишь выбранную клавишу. Это не переключатель:
отпустил клавишу — микрофон снова замолчал. Так работает в Discord, Zoom, OBS,
браузере и где угодно ещё, потому что Periferia управляет звуковым сервером, а
не отдельной программой.

Проект завершён: он делает ровно то, ради чего создавался, и новых функций не
планируется. Две идеи, которые так и не вошли — RGB и компрессор — осознанно
вне рамок, а не «не доделаны». См. [Что готово](#что-готово-версия-10).

Это короткий русский README. Полное техническое описание (измерения, устройство
цепочки PipeWire, все детали настроек) — в английском [README.md](README.md).
Если ты никогда таким не пользовался, начни с
[инструкции для чайников](docs/getting-started.ru.md).

## Что это делает

- **push-to-talk** — читает клавиши через evdev, открывает микрофон при нажатии
  и закрывает при отпускании, с задержкой, чтобы не обрезать последнее слово.
  Есть клавиша паники. Следит сразу за всеми клавиатурами.
- **виртуальный микрофон** — создаётся из физического, с плавной регулировкой
  громкости (без щелчков). На это опирается push-to-talk.
- **обработка** — включает встроенные в PipeWire шумоподавление (RNNoise),
  эхоподавление и детектор речи. Это свойства модуля PipeWire, а не свой DSP.
- **макросы** — записывают нажатия клавиш с таймингом и проигрывают их по одной
  клавише, глобально или отдельно для конкретного окна. Только клавиатура,
  микрофон не затрагивается.
- **профили** — переназначение клавиш, отключение клавиши целиком, скорость
  указателя; на KWin профиль следует за активным окном.
- **CLI, окно и индикатор** — `periferia`, `periferia-gui`, `periferia-tray`.

Демон следит за файлом конфигурации: записанный макрос или изменённый профиль
подхватывается примерно за секунду.

## Проверка, что всё работает

`periferia tui` открывает самопроверку в терминале: восемь пунктов, каждый
заканчивается «прошло» или «не прошло», без стены логов. Пункты 5 и 6 просят
тебя нажать и подержать клавишу PTT и клавишу паники; остальные — автоматически,
клавиша `a` запускает всё, что не требует ввода.

```bash
systemctl --user stop periferia   # если служба уже стоит
periferia tui
```

Если микрофон проверить нельзя (нет звукозаписи под рукой), есть
`periferia gate-check`: она показывает, поднимается ли громкость источника, пока
ты держишь PTT. Это доказывает, что клавиша дошла до демона и рампа
сработала, — но не то, что приложение реально открывает источник.

## Установка

### Одним файлом (AppImage)

```bash
chmod +x Periferia-*.AppImage
./Periferia-*.AppImage
```

Ничего не устанавливается. Собранный файл можно положить в `~/Applications`, и
он появится в меню приложений сам.

### Flatpak

Манифест лежит в `packaging/flatpak/`. CI собирает бандл на каждый push. Локально
нужны `flatpak-builder` и настроенный remote Flathub:

```bash
flatpak-builder --user --install build-dir \
  packaging/flatpak/org.periferia.Periferia.yaml
flatpak run org.periferia.Periferia
```

Тот же бандл служит и демоном, и индикатором:

```bash
flatpak run org.periferia.Periferia daemon
flatpak run org.periferia.Periferia tray
```

### Из AUR (Arch)

`packaging/aur/PKGBUILD` собирает один пакет с демоном, окном и индикатором:

```bash
cd packaging/aur
makepkg -si
```

Для окна и индикатора нужен PySide6 (`pacman -S python-pyside6
python-ruamel-yaml`).

### Из исходников

```bash
git clone https://github.com/ldima8286-cmd/PythonPeriferia
cd PythonPeriferia
bash scripts/dev-setup.sh
source .venv/bin/activate
```

Нужен Python 3.11+ и `pipewire-utils`. Подробности, включая неизменяемые системы
(Fedora Atomic, Bazzite) и установку через `uv`, — в английском
[README.md](README.md#install). Там же разбор того, что и где реально
проверялось.

## Первый запуск

```bash
periferia check        # способна ли эта машина это запускать
periferia sources      # какие устройства захвата есть
periferia pick-key     # нажми клавишу и получи её значение для конфига
periferia init-config  # записать ~/.config/periferia/config.yaml
```

Полученную из `pick-key` клавишу впиши в `ptt_key`, затем направь приложения на
виртуальный микрофон:

```bash
periferia set-default
```

`periferia check` стоит прочитать внимательно: он говорит, читаются ли события
клавиатуры, доступен ли звуковой сервер и увидит ли звук Flatpak-приложение.
Если события клавиш не читаются — см. [docs/udev.md](docs/udev.md).

## Как пользоваться

Запусти демон (его ставит `scripts/dev-setup.sh`):

```bash
periferia-daemon
```

Держишь клавишу — микрофон открыт. Отпустил — микрофон закрывается через
`hold_ms`. Если держать дольше `latch_ms`, микрофон фиксируется открытым, и
закрывается следующим нажатием — когда нужны обе руки. По умолчанию фиксация
выключена. Демон клавиатуру только читает и никогда не перехватывает, поэтому
печатать можно как обычно.

Удобнее поставить службу пользователя:

```bash
periferia install-service
```

### Основные команды

| команда | что делает |
| --- | --- |
| `periferia check` | проверить окружение, показать, чего не хватает |
| `periferia status` | открыт ли микрофон прямо сейчас |
| `periferia sources` | список источников, отметить физический и его профиль |
| `periferia device` | какой источник захвата используется и какой профиль им управляет |
| `periferia devices` | список устройств ввода, похожих на клавиатуры |
| `periferia pick-key` | нажать клавишу и получить её значение для yaml |
| `periferia calibrate` | измерить карту и выдать готовую запись `devices:` |
| `periferia graph` | показать граф PipeWire так, как его читает очистка |
| `periferia ramp` | ручная рампа громкости, чтобы услышать щелчки до PTT |
| `periferia set-default` | сделать виртуальный микрофон источником по умолчанию |
| `periferia teardown` | выгрузить модули echo-cancel, оставшиеся после сбоя |
| `periferia config` | показать конфиг, который реально в силе |
| `periferia config --check` | показать, что не так с конфигом, до запуска демона |
| `periferia install-service` | установить systemd-юнит пользователя |
| `periferia macro list` | все макросы, чем играются и что внутри |
| `periferia macro check` | что не сработает и почему |
| `periferia profiles` | какие профили есть и что они делают |

Индикатор:

```bash
periferia-tray              # значок в трее, меню по клику
periferia-tray --overlay    # та же точка на рабочем столе
periferia-tray --window     # окно Qt, если трея в сессии нет
```

Зелёный — микрофон открыт, серый — закрыт, янтарный — занят другим
приложением. Когда демон не запущен, не показывается ничего.

## Конфигурация

`~/.config/periferia/config.yaml`, либо `$PERIFERIA_CONFIG`. Шаблон —
`config.example.yaml`. Значения, которые важнее всего:

| ключ | по умолчанию | заметки |
| --- | --- | --- |
| `audio.attack_ms` | 10 | меньше — ощущается мгновеннее |
| `audio.release_ms` | 60 | как быстро микрофон затухает |
| `audio.hold_ms` | 200 | держит микрофон открытым чуть после отпускания |
| `audio.curve` | exp | `exp`, `linear` или `s_curve` |
| `ptt.ptt_key` | auto | физическая клавиша, см. ниже |
| `ptt.device` | auto | какие клавиатуры слушать |
| `ptt.panic_key` | KEY_F12 | мгновенное заглушение, игнорирует `hold_ms` |
| `ptt.latch_ms` | 0 | держать столько — зафиксировать микрофон; 0 выключает |
| `ptt.max_press_ms` | 300000 | обрубить клавишу, удержанную дольше; 0 выключает |
| `processing.voice_detect` | true | режет тишину между фразами |
| `processing.stereo_to_mono` | true | публиковать один моно-канал (левый) |
| `processing.mono_from` | front-left | из какого канала берётся моно |
| `devices` | пусто | переопределения под конкретное устройство |
| `macros` | пусто | записанные последовательности нажатий |

О клавишах: evdev знает физические коды, а не раскладку. `KEY_V` — это
физическая клавиша V, которая на русской раскладке печатает `М`. Поэтому одна и
та же настройка работает в обеих раскладках. Для PTT плохо подходят
`KEY_W A S D` (это движение в играх); редко используемые — `KEY_Y`, `KEY_U`,
`KEY_H`, `KEY_N`, `KEY_GRAVE` (на русской раскладке это Н, Г, Р, Т, Ё).

Если конфиг написан с ошибкой, значение отлавливается при чтении, а
`periferia config --check` называет ключ и причину — вместо того чтобы стать
микрофоном, который открывается мгновенно, или логом, которого не видно.
Подробности и примеры: раздел Configuration в английском README.

## Если что-то не работает

- **Клавиши не определяются.** `periferia check` помечает недоступные
  устройства. См. [docs/udev.md](docs/udev.md).
- **Клавиша работает на одной клавиатуре, но не на другой.** Скорее всего,
  вторая закрыта правами доступа; `periferia check` перечислит узлы, которые не
  удалось открыть.
- **Микрофон открывается, но ничего не слышно.** Приложение всё ещё смотрит на
  физический источник. Сделай `periferia sources`, затем `periferia
  set-default`.
- **Щелчки при открытии и закрытии.** Увеличь `attack_ms` и `release_ms`.
- **Клавиши всё равно печатаются в приложение.** Устройство не перехвачено: так
  бывает, когда его раньше перехватила другая программа. Проверь
  `sudo fuser -v /dev/input/event5`.
- **После сбоя остался лишний модуль.** `periferia teardown`.

## Что готово (версия 1.0)

Готово:

- [x] стерео в моно: два канала действительно различаются (измерено), поэтому
      виртуальный микрофон публикует один моно-канал из левого
- [x] настройки под устройство: реестр `devices:` сопоставляет карту по свойствам
      PipeWire, `periferia calibrate` измеряет нужный канал, а демон меняет
      профиль при подключении и отключении железа
- [x] окно настройки конфига: по одному профилю и по одной записи устройства,
      комментарии сохраняются
- [x] профили ввода: переназначение, отключение клавиши, скорость указателя; на
      KWin профиль следует за активным окном
- [x] перенос профилей: `periferia profiles export/import`
- [x] строгая проверка конфига: тип, диапазон и допустимые имена у каждого
      значения, `periferia config --check` проверяет весь файл
- [x] чтение графа PipeWire напрямую через `pw-dump`
- [x] Flatpak: манифест и workflow сборки
- [x] AUR: PKGBUILD, готов к `makepkg -si`

Вне рамок:

- [ ] управление RGB со скриптами и профилями по времени суток — нужен прямой
      доступ к HID, который эта программа не запрашивает
- [ ] компрессор и де-эссер — не здесь: `filter-chain` не загружается, ставить
      их некуда. Для этого есть EasyEffects
